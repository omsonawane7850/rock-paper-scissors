# Rock Paper Scissors

A simple Rock Paper Scissors game built with React.js.

## Features

* Player vs Computer
* Random computer choice
* Winner and draw detection
* Score tracking
* Round tracking
* New Round
* Reset Game
* Responsive UI

## Tech Stack

* React.js
* JavaScript
* CSS
* Vite
* Custom React Hook

## Run Locally

```bash
npm install
npm run dev
```
